# ggvariant: Tidy, ggplot2-Native Visualization for Genomic Variants

A simple, opinionated toolkit for visualizing genomic variant data using
a 'ggplot2'-native grammar. Accepts VCF files or plain data frames and
produces lollipop plots, consequence summaries, mutational spectrum
charts, and cohort-level comparisons as standard 'ggplot2' objects.
Designed for both wet-lab biologists and experienced bioinformaticians.
